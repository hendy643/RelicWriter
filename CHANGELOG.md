# Changelog

All notable changes to RelicWriter, newest first. The About tab shows this file. Write for players: one short line per change, under the heading of the version it ships in.
Format: `## <version> · <date>` for a release (`## Unreleased` while it is not out), then one `- ` line per change.

## 1.1.0 · 25 October 2026
- New About tab with the version, credits and this list.
- Add items to your bag from the game's own item list: search by name (it forgives typos and capital letters), narrow it by category, type and quality. Items from Phantom Liberty are offered only when Phantom Liberty is switched on.
- The editor now follows the game version of your save. Level cap, skill limits, which skills are shown and the Perks tab all match that version, and Save Info lets you move a save up to a later patch of the same save format.
- Phantom Liberty can be switched on or off on Save Info, because the save does not record it.
- Linux: the game is found through Steam, Lutris and Heroic, and saves are found inside Wine and Proton prefixes.
- Linux: vehicle pictures now show, the same as on Windows.
- Flatpak can reach games installed on other drives and in ~/Games.

## 1.0.0 · 24 October 2026
- First release.
- Edit your character's level, attributes and skills.
- Set the level of every perk; unspent perk and Relic points stay in step.
- Change the face-shape presets of your appearance.
- Edit eddies and item stack sizes, with items shown by their in-game names.
- Unlock vehicles in your garage, with pictures from your own game install.
- Inspect the save's header and its raw node tree.
- The app checks for new versions and offers to install them.
